# Spigot Generator for MCreator 2026.1
An unofficial plugin for [MCreator](https://mcreator.net/), a code generator for Minecraft. This plugin adds a NeoForge generator.
**The current targeted Minecraft version is 1.20.1** (Based on the original framework by _Spectrall).
## Information
- Make sure you use MCreator 2026.1
- Based on the original framework by _Spectrall
